MANUAL AUDIT (No API Key):
==========================

Audit individual pages in Chrome:
1. Open page
2. Press F12 → Lighthouse tab
3. Click "Analyze page load"
4. Check: LCP, INP, CLS, TTFB, Score
5. Compare to targets:
   - LCP < 2.5s
   - INP < 200ms
   - CLS < 0.1
   - TTFB < 800ms
   - Score > 50

Start with Priority 1 pages above.
