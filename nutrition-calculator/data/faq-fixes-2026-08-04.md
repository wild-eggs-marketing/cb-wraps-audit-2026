# CMS FAQ corrections — 4 August 2026

A sweep of all 103 Menu items' FAQ fields (`zG08650jR`/`loB8_cYxl` = Q1/A1,
`im_35WFB0`/`lrC33foKY` = Q2/A2) against the official allergen analysis
(`data/fda-full-2026-07-28.json`) flagged seven items whose answers contradicted
the data. All seven were corrected via `upsertCMSItem` on collection `fEfKTjIH1`
and verified by read-back. **These go live on the next Framer publish** — CMS
content publishes with the site, not on save.

Mechanics note that bit us once mid-sequence: a partial `upsertCMSItem`
revalidates the item's existing multi-reference field, which Framer *returns*
as slugs but only *accepts* as item IDs. Every call below therefore re-sent
`IzMEvuZ8B` (Dietary Tags) with the IDs from `data/diet-tag-ids.json`, and
`draft:false` explicitly (the API defaults it, and defaults publish drafts).
