VALIDATION PROCEDURES
================================================================================

STEP 1: Google Rich Results Test
  URL: https://search.google.com/test/rich-results
  Process:
    1. Enter page URL
    2. Click "Test URL"
    3. Look for green checkmark
    4. Review schema card preview
  Time per page: 30-60 seconds

STEP 2: Google Search Console
  URL: https://search.google.com/search-console
  Process:
    1. Go to Enhancements > Structured Data
    2. Filter by type (Organization, LocalBusiness, MenuItem, etc.)
    3. Check for "0 errors"
    4. Note: May take 48-72 hours to appear
  Frequency: Bi-weekly during implementation

STEP 3: JSON Syntax Check
  URL: https://jsonlint.com/
  Process:
    1. Paste JSON-LD content
    2. Click "Validate JSON"
    3. Should show "Valid JSON"
  Time per schema: 1 minute

STEP 4: Schema.org Validator (Optional)
  URL: https://validator.schema.org/
  Process:
    1. Paste page HTML source
    2. Click "Validate"
    3. Check for valid schema types
  Time per page: 2-3 minutes

RECOMMENDED VALIDATION ORDER:
  1. JSON syntax (must pass before testing)
  2. Google Rich Results (visual feedback)
  3. Search Console (ongoing monitoring)
  4. Schema.org Validator (deep validation)
