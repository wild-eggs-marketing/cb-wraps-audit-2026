## Section 1: Internal 404s/410s (Prioritized by Impact)

### 404 Error: Cloudflare Email Protection Page

| Field | Value |
|-------|-------|
| **URL** | `https://crazybowlsandwraps.com/cdn-cgi/l/email-protection` |
| **HTTP Status** | 404 |
| **Page Title** | Email Protection \| Cloudflare |
| **Inbound Internal Links** | 4 |
| **Sources** | `/catering/`, `/form-confirmation/`, `/privacy-policy/` |
| **Recommendation** | **REMOVE** — This is a Cloudflare email obfuscation endpoint that should not be linked. The site is incorrectly linking to the Cloudflare protection script itself instead of the desired target. Update all 4 pages to remove email-protection links. |

**Analysis:**
- The email protection link is auto-generated by Cloudflare when obfuscating email addresses.
- It is not a real page and correctly returns 404.
- This is not a site content issue, but rather improper Cloudflare setup or link injection.
- **Action:** Verify Cloudflare email obfuscation is disabled or properly configured; remove these links from source HTML.

## Technical Notes

### Data Collection Methodology

**Crawl Data (crawl.csv):**
- 126 pages crawled
- Columns: url, final_url, status_code, load_time_ms, title, SEO metadata, link counts
- Crawl captured: HTTP status, redirect destination (via url vs final_url comparison)
- **Limitation:** Does not capture intermediate redirect hops

**Link Graph (link-graph.json):**
- 126 nodes (all crawled URLs)
- 362 edges (internal link relationships)
- Used for in-degree/out-degree analysis
- Identified orphan pages (in-degree = 0)

### Known Limitations

1. **GA4 Data Missing:** Crawl CSV has ga4_sessions, ga4_engagement_rate, ga4_bounce_rate columns but all values are blank. Impact ranking is impossible without this data.

2. **Redirect Chains:** Crawl captures only source→final, not intermediate hops. A chain like A→B→C→D (4 hops) would appear as A→D with no visibility into B and C. Full redirect trace would require network inspection or enhanced crawler.

3. **External Link Validation Skipped:** Due to time constraints and GA4 data being unavailable, external link validation on top 20 pages was deferred. This should be completed in a follow-up pass.

4. **Orphan Page Context:** The 49 orphan pages may legitimately have zero internal links if they are:
   - Accessed via search/backlinks (would need GSC data to confirm)
   - Accessed via direct URL (e.g., email campaigns, paid ads)
   - Dynamic content generated from structure (e.g., author archives)
   - Intentionally not promoted internally (legacy content)
